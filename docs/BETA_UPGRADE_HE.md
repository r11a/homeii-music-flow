# התקנה ושדרוג — HOMEii Flow 6.0.2

**כרטיס: `6.0.2` · מנוע: `1.0.2` · גרסאות יציבות.** שם הקובץ נשמר כדי שקישורים קיימים ימשיכו לעבוד.

> [!WARNING]
> **בשדרוג מ־5.9.3 חייבים להתקין ולהגדיר את המנוע לפני החלפת הכרטיס.** גרסה 6 דורשת את HOMEii Flow Engine ואת אינטגרציית Music Assistant הרשמית ב־HA. החלפת הכרטיס לבדה אינה מספיקה.

## סדר העדכון

1. לשמור גיבוי HA, הגדרות הכרטיס, כתובת המשאב וקובצי הגרסה הקיימת.
2. להתקין את [HOMEii Flow Engine 1.0.2](https://github.com/r11a/homeii-flow-engine/releases/tag/v1.0.2) דרך HACS או להעתיק את תיקיית `custom_components/homeii_flow` מהחבילה למיקום המתאים ב־HA.
3. לאתחל את Home Assistant ולוודא שהמנוע נטען ומחובר ל־Music Assistant. בהתקנה קיימת משאירים את רשומת האינטגרציה וההגדרות שלה.
4. להתקין את [HOMEii Music Flow 6.0.2](https://github.com/r11a/homeii-music-flow/releases/tag/v6.0.2).
5. להשאיר משאב JavaScript אחד בלבד. בהתקנה ידנית: `/local/community/homeii-music-flow/homeii-music-flow.js?v=6.0.2`. ב־HACS משאירים את הנתיב המנוהל של HACS.
6. לרענן באופן מלא את הדפדפן או אפליקציית Companion ולבדוק את שתי הגרסאות באבחון.

המנוע 1.0.2 הוא עדכון תחזוקה: התנהגות הריצה נשארה כמו 1.0.1, מלבד מספר הגרסה. אין שינוי פורמט אחסון או דרישת API חדשה. עיצוב המניפה, האייקונים, הפונטים והאנימציות נמצאים בכרטיס.

## דרישות

Music Assistant פעיל עם API schema 63 ומעלה, האינטגרציה הרשמית שלו ב־HA ונגן זמין. כתובת MA הישירה ופרטי ההתחברות מוגדרים במנוע בלבד. אין להכניס טוקנים ל־YAML של הדשבורד או לפרסם אותם ב־Issues. היכולות תלויות גם בנגן ובספק המוזיקה.

שני הרפוזיטוריז ציבוריים. המנוע הוא אינטגרציה מותאמת של HA, לא תוסף/App, ואינו מחליף את Music Assistant.

## חזרה לאחור

כדי לחזור ל־6.0.1, מחזירים את קובץ הכרטיס ואת כתובת המשאב השמורה ומרעננים את הלקוחות. חזרה מלאה ל־5.9.3 מחייבת גם שחזור ההגדרות המתאימות ובדיקה של תזמונים וכללי מנוע שנשארים פעילים גם כשהכרטיס נסגר או משונמך. אם צריך לחזור למצב המלא הקודם, משתמשים בגיבוי HA. אין לערוך ידנית קובצי `.storage`.
